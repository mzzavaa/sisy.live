# SISY.live - Events Hub for Women Experts

Live site: https://sisy.live

Part of the [SISY ecosystem](https://sisy.world) - visibility infrastructure for women experts.

## About

SISY.live is the events hub where women experts take the stage. Panels, webinars, virtual summits, and practice stages - built around women experts and the audiences who want to hear from them.

## SISY Ecosystem

| Site | Purpose |
|------|---------|
| [sisy.world](https://sisy.world) | Main platform hub |
| [sisy.my](https://sisy.my) | Expert profiles |
| [sisy.live](https://sisy.live) | Events hub |
| [sisy.guru](https://sisy.guru) | Mentoring marketplace |
| [sisy.cam](https://sisy.cam) | Video recording tool |
| [sisy.work](https://sisy.work) | Career and opportunities board |
| [sisy.social](https://sisy.social) | Community |
